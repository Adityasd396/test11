YouTube search 
Enable YouTube Data API v3 in Google Cloud, restrict the key to that API, and set YOUTUBE_API_KEY. Reload Solace and search from Add video to verify it.

   
Account email 
Configure SOLACE_SMTP_HOST, SOLACE_SMTP_PORT, optional SOLACE_SMTP_SSL, provider credentials in SOLACE_SMTP_USERNAME and SOLACE_SMTP_PASSWORD, and a verified SOLACE_MAIL_FROM. Use the published HTTPS origin for account links. Check that your host permits outbound SMTP, then test email verification with a test account.

   
Web push 
Set SOLACE_PUSH_PUBLIC_KEY, SOLACE_PUSH_PRIVATE_KEY, and SOLACE_PUSH_CONTACT in the web app and dispatcher. Install pywebpush in the dispatcher environment and supervise python -m flask --app app dispatch-push every few seconds. Confirm outbound access to supported browser push services and device permission before sending a test DM.
A configured key does not confirm a running worker or device delivery.
PythonAnywhere worker requirements

   
Google credentials 
Enable the Search Console and Analytics Data APIs in Google Cloud as needed. Install google-auth and requests in the web environment, provide application credentials through GOOGLE_APPLICATION_CREDENTIALS, and grant the service account read access to the relevant properties.

   
Search Console 
Verify site ownership in Search Console. For HTML-tag verification, publish the value from the verification tag in Site setup. Set SOLACE_SEARCH_PROPERTY to the verified property, then submit the public sitemap in Search Console.
Open Google reports

   
Google Analytics 4 
Set SOLACE_GA4_PROPERTY to the numeric property ID. Grant the service account read access and check Acquisition or Realtime under Google reports. This connection reads existing GA4 data. It does not install a tracking tag.
Open Google reports

   
Database backups 
Run tools/storage.py backup with the live instance path and verify the backup with tools/storage.py verify. Set SOLACE_BACKUP_DIRECTORY to the private parent of timestamped backup folders so Solace can find the manifests.
